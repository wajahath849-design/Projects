# Power BI dashboard

Open `PBI\AI Model Analytics.pbip` in Power BI Desktop.

The checked-in project contains four pages:

- Executive Overview
- Live Prediction
- Model Performance
- Data Explorer

Connection:

- Server: `localhost,14330`
- Database: `AIModelAnalytics`
- Authentication: Windows
- Storage mode: DirectQuery

Power BI local settings and caches under `.pbi` are intentionally excluded from Git.
On first open, approve the native database connection and select Windows
authentication. Use Ctrl+click on page-navigation buttons while editing.
