# AI-Powered Data Center Operations Intelligence Platform

Portfolio project for RAG-based conversational analytics, secure text-to-SQL, and Power BI over synthetic data modeling realistic data-center operations from 2015 through 2025.

Steps 1–7 are implemented. The project now includes verified data quality and cleaning, an executable canonical contract, an indexed SQLite analytical database, a shared KPI layer with SQL/Python reconciliation, and a source-controlled Power BI foundation. Steps 8–17 add adaptable imports, RAG, OpenAI-powered text-to-SQL, security, application UI, dashboard refinement, and evaluation.
