# Power BI Dashboard Pages

The PBIP project contains seven populated 1600 × 900 report pages, 223 native
Power BI visuals, two slicers on every page, and one registered executive
theme. Open `powerbi/PBI/DataCenter Executive Dashboard.pbip` in Power BI
Desktop and select **Refresh** to load the local governed CSV snapshots.

The design follows the supplied executive reference: dark navy header and
navigation rail, numbered color-coded page badge, white KPI cards, a two-row
chart grid, and a lower evidence table. Visuals remain source-backed rather
than using the decorative values shown in the reference image.

## Empty-dashboard recovery

If Power BI Desktop shows blank pages, first check the page tabs. Five pages
means an older generated project is open. Close it without saving over the
source, reopen the exact `.pbip` path above, and select **Home → Refresh**. If
the folder was moved, run `python scripts/export_powerbi_snapshots.py` followed
by `python scripts/build_powerbi_project.py` before reopening; this rewrites all
local CSV source paths for the current location.

## Page map

| Page | Operating question | Primary views |
|---|---|---|
| Executive Operations Overview | Where is the fleet healthy or degrading? | PUE trend, downtime ranking, facility scorecard, current simulated health |
| Infrastructure Performance | Where is capacity or network pressure building? | CPU/memory trend, facility latency ranking, server performance detail |
| Energy & Reliability | How do power, cooling and downtime compare? | PUE trend, downtime by root cause, facility energy/reliability table |
| Reliability & Incident Intelligence | What incident evidence is recurring? | incident trend, root-cause ranking, incident detail |
| Predictive Operations | Which facilities and servers require review? | risk-level distribution, facility health ranking, server risk evidence |
| Cost & Sustainability | Where are modeled cost, carbon and efficiency opportunities concentrated? | monthly cost trend, facility cost comparison, governed sustainability snapshot |
| Reliability Impact | What changed around incidents and what exposure is modeled? | exposure trend, root-cause exposure ranking, seven-day before/after evidence |

## Chart map and interpretation rules

- Lines are used for the 132 monthly observations from 2015–2025; they are
  historical trends, not forecasts.
- Horizontal bars compare facilities or recorded root causes and start from
  zero under Power BI defaults.
- Tables provide exact lookup and retain source, facility, date, severity, and
  metric context.
- Cost and carbon visuals use `FactCostCarbon`, a monthly facility snapshot
  generated by the governed sustainability engine.
- Reliability-impact visuals use `FactIncidentImpact`. Seven-day before/after
  changes are descriptive associations and never causal claims.
- Live scores use only `FactLiveOperationsSnapshot`; raw volatile telemetry is
  intentionally excluded from the Power BI model.

## Interactions and caveats

- Facility and context slicers filter their page; charts cross-filter through
  the one-way star-schema relationships.
- Historical relative dates anchor to 31 December 2025, the latest canonical
  data date, rather than the computer clock.
- All operational history, prices, carbon intensities, incidents, and
  simulations are synthetic portfolio data.
- Power BI Desktop may show a manual-refresh banner after source regeneration.
  Use **Refresh now**; the source paths are rebuilt from the current project
  location by the generator.
